# «Первый шаг» — навигатор иностранного студента в MAX

Чат-бот помогает иностранному студенту разобраться с документами после приезда в Россию. Внутри — персональный чек-лист, карточки с порядком действий, отметки о выполнении и напоминания о сроках.

- Бот в MAX: [@t327_hakaton_max_bot](https://max.ru/t327_hakaton_max_bot)
- Репозиторий: [github.com/Chiryusha/MAX_BOT](https://github.com/Chiryusha/MAX_BOT)
- Техническая информация для проверки: [docs/SUBMISSION.md](docs/SUBMISSION.md)

## Пользовательские сценарии

При первом запуске бот предлагает выбрать ситуацию:

- **Только приехал** — дата въезда устанавливается на текущий день, а миграционная карта и регистрация выделяются как первоочередные задачи.
- **Уже учусь** — студент отмечает имеющиеся документы и получает список того, что осталось оформить или проверить.
- **Просто посмотреть** — чек-лист открывается без изменения и сохранения данных.

В каждом пункте указаны назначение документа, место оформления, необходимые документы, ориентир по сроку и возможные последствия просрочки. Выполненный пункт можно вернуть в работу. Напоминания доступны только для активных пунктов и автоматически отменяются после выполнения.

Дата въезда не может быть позже текущего дня. Для напоминания можно выбрать интервал в 1, 2, 3 или 7 дней до срока, изменить дедлайн или полностью отключить уведомление.

## Стек и устройство проекта

- Node.js 24;
- официальный пакет `@maxhub/max-bot-api`;
- long polling для локального запуска;
- webhook для размещения на сервере;
- JSON-файл для состояния пользователей и напоминаний;
- Docker и Docker Compose;
- встроенные тесты `node:test`.

Основные модули:

```text
src/bot.js         обработчики MAX, запуск polling/webhook и health-check
src/scenarios.js   сообщения и inline-клавиатуры
src/domain.js      даты, дедлайны, прогресс и правила напоминаний
src/storage.js     атомарное сохранение состояния в JSON
src/reminders.js   отправка уведомлений и повторные попытки
src/content.json   содержимое восьми шагов чек-листа
src/tls.js         подключение сертификата для MAX API
```

## Локальный запуск

Понадобятся Node.js 24.5 или новее и токен бота MAX.

```powershell
Copy-Item .env.example .env
npm ci
npm test
npm start
```

В `.env` необходимо заполнить:

```dotenv
MAX_BOT_TOKEN=токен_бота
BOT_MODE=polling
```

После запуска бот работает через long polling. Проверить процесс можно по адресу `http://localhost:3000/healthz`.

## Переменные окружения

| Переменная | Обязательность | Назначение |
| --- | --- | --- |
| `MAX_BOT_TOKEN` | всегда | токен бота, полученный в MAX |
| `BOT_MODE` | нет | `polling` или `webhook`, по умолчанию `polling` |
| `PORT` | нет | HTTP-порт health-check и webhook, по умолчанию `3000` |
| `STATE_FILE` | нет | путь к JSON-файлу состояния |
| `REMINDER_POLL_INTERVAL_MS` | нет | интервал проверки напоминаний в миллисекундах |
| `DEFAULT_TIMEZONE_OFFSET_MINUTES` | нет | смещение часового пояса, по умолчанию `180` |
| `PUBLIC_BASE_URL` | для webhook | внешний HTTPS-адрес сервиса |
| `WEBHOOK_SECRET` | для webhook | секрет проверки входящих запросов MAX |
| `WEBHOOK_PATH` | нет | собственный путь webhook; без него путь строится из хеша токена |

Файл `.env` добавлен в `.gitignore`. Токен и webhook-секрет не должны попадать в Git.

## Запуск в Docker

```powershell
Copy-Item .env.example .env
docker compose up --build -d
docker compose logs -f bot
```

Состояние сохраняется в именованном volume `bot-data`. Контейнер запускается от пользователя `node` и содержит health-check.

Остановка:

```powershell
docker compose down
```

## Webhook-режим

Для webhook нужен доступный из интернета HTTPS-адрес:

```dotenv
BOT_MODE=webhook
PUBLIC_BASE_URL=https://bot.example.ru
WEBHOOK_SECRET=случайная_длинная_строка
PORT=3000
```

При старте приложение регистрирует webhook в MAX. Одновременно использовать webhook и long polling нельзя. Описание служебных HTTP-методов находится в [docs/openapi.yaml](docs/openapi.yaml).

## Данные и ограничения

Состояние хранится локально в `data/state.json` и создаётся автоматически. Для запуска нескольких экземпляров потребуется общее хранилище, например PostgreSQL или Redis.

Справочные сроки зависят от гражданства, основания пребывания, региона и требований вуза. Бот напоминает об этом в каждой карточке; перед подачей документов информацию необходимо сверить с международным отделом вуза и официальным ведомством.
